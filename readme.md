## ⚙️ Local Development Setup

Follow these instructions to run the portfolio dashboard locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/magnet-solution/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the development server:**
   ```bash
   npm run dev
   ```

4. **Compile for production deployment:**
   ```bash
   npm run build
   ```
